# 第18章 学习小结与下一步

> 恭喜你读到这里。这一章不教你新知识，而是**收束**：回顾你学到了什么，给你一份"接下来做什么"的行动清单，以及持续精进的资源入口。

## 18.1 你学到了什么（全书记忆卡）

### 概念层（Part 0）

- **大模型**：预测下一个 token 的概率引擎，无状态、无手、会幻觉；
- **提示词**：给模型的任务说明书（系统提示 vs 用户提示）；
- **Agent**：模型 + 工具 + 循环（ReAct 思考→行动→观察）；
- **Harness**：把模型、工具、循环、记忆、护栏装成可驾驶的"车"。

### 项目层（Part 1）

- **dsh** 是 DeepSeek 开源的 agent harness，中心思想是**一切皆插件**（Cordis 驱动）；
- 跑起来：`pnpm install` → `pnpm dsh web`（127.0.0.1:3080）；
- **免构建源码启动**：tsx + `tsconfig.base.json` 的 `paths` 映射，改 `src` 即生效；
- 目录：`packages/`（能力包）、`vendor/`（Cordis 内联）、`apps/`（入口与出厂预设）、`docs/`（文档）。

### 源码层（Part 2）

- **插件契约**：`name` / `inject` / `apply`；`ctx` 是服务仓库；注册是可逆 effect；
- **会话日志**：只追加的 `SessionEvent` 流；**模型可见即已记录**（`deriveMessages` 从日志投影）；
- **工具**：`defineTool`；必填写 `required: true`，可选**省略** required；
- **LLM**：seam 三角色（Definition=`ctx.llm` / Provider=DeepSeek 适配器 / Consumer=`agent-loop`）；
- **主循环**：`turn`（一轮）⊃ `step`（一次模型请求+工具调用）；`agent/pre-step` 是首选注入点；
- **预设**：`defaultId = settings.default ?? config.default`——零改核心切换默认人设/工具；
- **实战**：加工具 = 写插件包 + 预设挂一行（你已会）。

### 进化层（Part 3）

- 加能力 = 找标准扩展点（注册服务 / 监听事件 / 组合预设 / 扩展会话事件）；
- 四阶段路线：私有工具 → 知识库/记忆 → 多 Agent → 终身自治。
