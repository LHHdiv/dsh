# 第11章 工具系统（tools / defineTool）

> 工具是 Agent 的"手"。本章讲 dsh 怎么**声明**一个工具、有哪些**规则**，以及它怎么被**带保护地执行**。

## 11.1 工具注册表 ctx.tools

`packages/core/tools` 拥有 `ctx.tools`。它做两件事：

1. **作用域化注册表**：工具注册到某个作用域（scope），从而不同会话/agent 可以有不同的工具集；
2. **带保护的执行管线**：调用工具前后有一套 `tools/pre-execute → tools/execute → tools/post-execute` 的瀑布事件，可做鉴权、日志、审批。

## 11.2 defineTool：工具的"出生证明"

声明一个工具，用 `defineTool({...})`。定义位于 `packages/core/tools/src/schema.ts`（第 545 行）：

```ts
export function defineTool<const S extends ParameterSchemaSpec, const O extends ValueSchemaSpec>(
  options: DefineToolOptions<S, O>,
): ToolDefinition
```

一个工具至少包含：

- `name`：工具名（模型调用时用的名字）；
- `description`：给模型看的说明（决定模型"懂不懂该用它"）；
- `parameters`：入参 JSON Schema（`action`、`name`、`keyword` 这类）；
- `output`：输出 schema + `render`（决定对话里怎么展示结果）；
- `execute(args)`：真正干活的异步函数。

## 11.3 必填参数规则（你踩过的坑）

这是初学者最容易错的地方，来自 `schema.ts` 的约束：

> `parameters` 每个字段可声明 `required: true`、`enum`、`additionalProperties: false` 等。

**关键规则：必填只能写 `required: true`；可选参数应「省略 `required` 键」，绝不能写 `required: false`。**

错误写法（会构造期报错 `parameters.name.required must be true when present`）：

```ts
parameters: {
  name: { type: 'string', required: false }  // ❌ 不允许
}
```

正确写法（可选就省略 required）：

```ts
parameters: {
  action: { type: 'string', required: true, enum: ['list', 'read', 'search'] },
  name:   { type: 'string' },   // ✅ 可选：省略 required
  keyword:{ type: 'string' }
}
```

> 小白意义：这不是 dsh 故意刁难，而是 JSON Schema 的语义——`required` 是一个**布尔列表的语义字段**，存在即必须为 `true`。记住这一条，能省你两小时 debug。

## 11.4 执行管线：调用不是"直接跑函数"

当模型决定调用工具，框架并不会简单调一下 `execute`。它走一条**受控管线**（结合第 10 章的事件）：

```
模型请求调用 tool/call
   → tools/pre-execute   (可拦截/鉴权/记录)
   → tools/execute       (真正执行 execute())
   → tools/post-execute  (可后处理)
   → tool/result 入会话日志  (模型下一轮"看到"结果)
```

这意味着：你可以监听 `tools/pre-execute` 实现"危险工具需人工审批"，监听 `tools/post-execute` 做结果缓存——**不改工具代码即可加横切逻辑**。

## 11.5 学习的范例工具

仓库里有 30+ 处 `ctx.tools.register(defineTool({...}))`，推荐两个对照读：

- `packages/todo/tool-todo/src/index.ts`（第 149 行）：最规范的"整体列表替换"工具，适合理解 `defineTool` 全貌；
- `packages/notes/tool-my-notes/src/index.ts`：你自己写的私有工具（下一章逐行讲）；
- `packages/fs/tool-fs/src/read.ts`、`write.ts`、`edit.ts`：文件操作类工具。

## 11.6 小结

- 工具经 `defineTool` 声明，注册到 `ctx.tools` 的作用域注册表。
- 必填写 `required: true`；可选**省略** `required`，勿写 `false`。
- 工具执行走 `pre-execute → execute → post-execute` 受控管线，便于加护栏。
