第1章 什么是大模型（LLM）

大模型就是一个**被喂了海量文本、学会"预测下一个字"的超级统计机器**。

🎯
本文学系目标用生活化比喻理解大模型是什么、能做什么、为什么需要 Agent 来驾驭它。

第1章 什么是大模型（LLM）

在谈 dsh、Agent、Harness 之前，必须先弄懂最底层那块"砖"：大模型（Large Language Model，LLM）。 后面的所有上层建筑，都是为了"用好它"而存在的。

1.1 一句话理解大模型

大模型就是一个被喂了海量文本、学会"预测下一个字"的超级统计机器。

  • 你给它一段话："今天天气真..."
  • 它会根据从训练数据里学到的规律，猜下一个最可能的字："好"。
  • 把"好"接在后面，再猜下一个，如此循环，就生成了一整段回答。

它没有真正的"理解"，但它从海量人类文本里，学到了语言、知识、逻辑的统计规律，所以表现得很像"懂"。理解这一点很重要：它是概率引擎，不是有意识的脑。

1.2 两个关键概念

Token（词元）

模型不是按"字"或"词"处理文字，而是按 token（词元）。中文里一个字往往拆成 1~2 个 token，英文一个单词可能是一个或多个 token。

  • 模型有上下文窗口（context window）限制：一次能"看到"的 token 总数有限（比如几万 token）。
  • 这就像人的短期记忆容量：超出窗口的内容，模型就"忘记"了。

小白提示：你可以把 token 粗略理解为"模型的最小记忆单位"。窗口越大，模型一次能记住的上下文越多。

参数量与"知识"

模型在训练时把世界知识"压缩"进了几百亿甚至更多的参数里。所以它能回答很多事实性问题——但这些知识停留在训练截止时间，且可能出错（幻觉）。

1.3 大模型能做什么、不能做什么

能做的 不能做的（需要外部帮助）
写作、翻译、总结、写代码 主动获取实时信息（查网页、读文件）
回答知识类问题 执行动作（发邮件、跑命令、改数据库）
按照指令推理、规划 长期记住你上个月的对话（无状态）
处理你"粘贴进去"的文本 保证 100% 正确（会幻觉）

注意最后一行：大模型本身是无状态的。每次对话，它只看到你这次传给它的内容；它不"记得"上次。这种"没有手、没有记忆、不会主动做事"的特点，正是需要 Agent 与 Harness 的原因。

1.4 一个生活比喻

把大模型想象成一位博学但被蒙住眼睛、绑在椅子上、记忆只有 5 分钟的天才学者：

  • 你（用户）把资料念给他听（输入提示）；
  • 他能基于听过的东西侃侃而谈（生成回答）；
  • 但他够不到桌上的书（不能访问外部工具）；
  • 也记不住上一拨访客说了什么（无状态）；
  • 更不会自己站起来去办事（不会主动行动）。

要让这位学者真正帮你完成任务，你需要给他配：

  • 一双手（工具 / Tools）：让他能查资料、跑程序；
  • 一个笔记本（记忆 / Memory）：把重要的事记下来；
  • 一个工作流程（循环 / Loop）：想一步、做一步、看结果、再想下一步；
  • 一套车架把这些装起来（框架 / Harness）。

后面三章，我们依次讲清"提示词（怎么跟他说话）"、"Agent（给他手和循环）"、"Harness（把他装成一辆能开的车）"。

1.5 小结

  • 大模型 = 预测下一个 token 的概率引擎，强大但无状态、无手、会幻觉。
  • token 与上下文窗口，决定了它一次"能记住多少"。
  • 它的能力边界，恰好定义了 Agent 与 Harness 的存在价值。
